# 1. 🚨 TOP SYSTEM AREA IS BEING TREATED AS PART OF THE APP

This is the first thing I noticed from the screenshots.

Look at the top of the screens.

The Android status bar:

> 11:37
> Wi-Fi

is visually sitting **on top of / extremely close to the application content**.

almost touching the system area.

This is not a branding issue.

This is a **layout/safe-area issue**.

### The app content needs a proper top inset.

Conceptually:

```text
┌─────────────────────────┐
│     SYSTEM STATUS BAR   │ ← OS
├─────────────────────────┤
│                         │
│ ← Back                  │ ← APP TOP BAR
│                         │
│ Page title              │
│ Subtitle                │
│                         │
```

NOT:

```text
┌─────────────────────────┐
│ 11:37  icons            │
│ ← Back   Page title     │ ← collision
│                         │
```

### Add this as a hard rule:

> **Never position application UI underneath the Android status bar unless intentional edge-to-edge behavior is explicitly implemented with correct insets.**

And if edge-to-edge is being used:

> **Apply WindowInsets consistently to every screen and every top app bar.**

This should be **non-negotiable**.
